## Structure is just plot by another name

Writing a novel means arranging chapters, cutting repetition and keeping the flow clean.
Engineering is the same discipline, only the audience is both human and machine.

### Three things code taught me

1. Anything written twice should be written once.
2. Keep old drafts; versions are a project's memory.
3. Ship early, edit later.

> Writing is rewriting — which is exactly what refactoring is.

Sample snippet:

```python
def word_count(text: str) -> int:
    return len([w for w in text.split() if w.strip()])
```

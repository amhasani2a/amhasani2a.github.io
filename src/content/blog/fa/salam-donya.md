## ساختار، همان طرح داستان است

وقتی یک رمان می‌نویسی، فصل‌ها را می‌چینی، تکرار را حذف می‌کنی و جریان را تمیز نگه می‌داری.
برنامه‌نویسی هم دقیقاً همین است؛ فقط مخاطبش هم‌زمان انسان و ماشین است.

### سه چیز که از کد یاد گرفتم

1. هر چیزی که دو بار تکرار شد، باید یک بار نوشته شود.
2. نسخهٔ قبلی را دور نریز؛ نسخه‌ها حافظهٔ پروژه‌اند.
3. زود منتشر کن، بعد ویرایش کن.

> نوشتن یعنی بازنویسی؛ دقیقاً مثل ریفکتور.

کد نمونه:

```python
def word_count(text: str) -> int:
    return len([w for w in text.split() if w.strip()])
```
